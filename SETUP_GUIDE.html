Robinhood Connection

A self-hosted options-wheel dashboard for your Robinhood account — on a Raspberry Pi, or on the computer you already own.

github.com/justintimefordinner-lang/Robinhood-Connection

Start here: let Claude do it

You don't need to understand a single command in this guide.

  1. Install Claude Code from claude.ai/code on the computer you're setting this up from.
  2. Start it, and give it this file.
  3. Say: “Set up the Robinhood Connection dashboard for me using this guide.”
  4. Answer the questions it asks, and paste back anything it wants to see.

Claude clones the repository, installs what's missing, writes your configuration, walks you through the Robinhood login, and starts everything running. The rest of this guide is written so Claude can follow it exactly — and so you can do it by hand if you'd rather.

One rule, either way. Never paste your Robinhood password into a chat window, a screenshot, or a public issue. It belongs in one place: the .env file on your own machine. Claude will tell you where to type it — it never needs to see it.

01What you're setting up

Two halves that only ever talk through a folder of files on disk:

PieceWhat it does
appfiles/
Next.js dashboard		Everything you look at — Portfolio, Stocks, Options, P&L, Volatility, Morning Brief, Research.
databridge/
Python program		Reads your Robinhood account and public market data, then writes the files the dashboard renders.

The bridge is read-only. It cannot place, change, or cancel a trade. There is no order path anywhere in the code — it only reads positions and market data.

Choose where it runs

Path A

Raspberry Pi

Runs around the clock, so the Morning Brief and live data are always current and you can open it from your phone. The recommended home.

Path B

Your own computer

Nothing extra to buy. Data refreshes only while your machine is awake and the program is running.

Start on a computer and move to a Pi later if you like — the setup is the same either way.

02Before you start

  • A Robinhood account with authenticator-app two-factor turned on (Account → Security). Text-message two-factor won't work for unattended running.
  • Node.js 20.9+ — the dashboard needs it.
  • Python 3.10+ — the bridge needs it.
  • Git.

To see what you already have:

node -v
python3 --version
git --version

03Try it first — no account needed

Before wiring up anything real, look at the whole dashboard filled with a built-in demo portfolio:

git clone https://github.com/justintimefordinner-lang/Robinhood-Connection.git
cd Robinhood-Connection/appfiles
npm install
npm run dev

Open http://localhost:3001 and click Example in the header. Every screen fills with synthetic data. Nothing touches Robinhood and no credentials are involved. Press Ctrl+C to stop.

Path ARaspberry Pi — always on

Tested on a Raspberry Pi 4 or 5 running 64-bit Raspberry Pi OS.

A1Prepare the system

sudo apt update && sudo apt full-upgrade -y
sudo apt install -y git python3-venv python3-pip build-essential

Install Node 20 from NodeSource — the version in Raspberry Pi OS's own repository is usually too old:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v      # expect v20.x

Install PM2, which keeps everything running and brings it back after a reboot:

sudo npm install -g pm2

If your Pi has 4 GB of RAM or less, give it more swap so the dashboard build doesn't run out of memory partway through:

sudo dphys-swapfile swapoff
sudo sed -i 's/^CONF_SWAPSIZE=.*/CONF_SWAPSIZE=2048/' /etc/dphys-swapfile
sudo dphys-swapfile setup
sudo dphys-swapfile swapon

A2Get the code

cd ~
git clone https://github.com/justintimefordinner-lang/Robinhood-Connection.git
cd Robinhood-Connection

A3Build the dashboard

cd ~/Robinhood-Connection/appfiles
npm install
npm run build          # several minutes on a Pi — that's normal

A4Set up the bridge

cd ~/Robinhood-Connection/databridge
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env

Fill in these four values, then save with Ctrl+O, Enter, Ctrl+X:

ROBINHOOD_USERNAME=your_email@example.com
ROBINHOOD_PASSWORD=your_password
ROBINHOOD_TOTP_SECRET=          # see section 05 — needed for 24/7
APP_DATA_DIR=/home/YOUR_USERNAME/Robinhood-Connection/appfiles/data

Replace YOUR_USERNAME with whatever whoami prints.

A5First login

cd ~/Robinhood-Connection/databridge
.venv/bin/python export_to_app.py

If you left ROBINHOOD_TOTP_SECRET blank it asks for the six-digit code from your authenticator app. When it finishes you should see:

Wrote /home/.../appfiles/data/snapshot.json  (1 account(s), N positions).

That file is your dashboard's data. If it appears, the hard part is behind you.

A6Start everything

Open the process definitions and correct the paths to match your username:

cd ~/Robinhood-Connection
nano ecosystem.config.js     # update every "cwd" and "script" path
pm2 start ecosystem.config.js
pm2 save
pm2 startup                  # then run the command it prints back
pm2 list

A7Open it

From any device on the same network, visit http://<your-pi-ip>:3001. Find the address with hostname -I.

Path BYour own computer

Works on macOS, Linux, and Windows — use PowerShell, or WSL if you prefer Linux commands.

B1Get the code

git clone https://github.com/justintimefordinner-lang/Robinhood-Connection.git
cd Robinhood-Connection

B2Set up the bridge

cd databridge
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env

Open .env in any text editor and fill in your username, password, and:

APP_DATA_DIR=/full/path/to/Robinhood-Connection/appfiles/data

That must be the full, absolute path — on Windows it looks like C:\Users\you\Robinhood-Connection\appfiles\data.

B3First login

python export_to_app.py

Enter your six-digit code when asked, and look for the Wrote … snapshot.json line.

B4Start the dashboard

In a second terminal:

cd Robinhood-Connection/appfiles
npm install
npm run dev

Open http://localhost:3001.

B5Keep the data fresh

Back in the first terminal, leave this running whenever you want live data:

cd Robinhood-Connection/databridge
python auto_push.py

It refreshes positions about once a minute and rebuilds the Morning Brief and research screens on their own slower schedules. Closing the terminal stops the updates — the dashboard keeps showing the last data it received. Once a day, for closed-trade history and the P&L page:

python sync_trade_history.py

05Two-factor: the TOTP secret

A Pi that runs unattended needs to generate its own login codes — otherwise it stops the first time the session expires and nobody is there to type one.

  1. In Robinhood: Account → Security → Two-Factor Authentication → Authenticator App.
  2. When the QR code appears, choose “Can't scan it?” or “Enter code manually.”
  3. Copy the long string of letters and numbers. That's the secret key — not the six-digit code that changes every thirty seconds.
  4. Put it in .env as ROBINHOOD_TOTP_SECRET=…

Running on your own computer and happy to type a code now and then? Leave it blank.

06Checking that it worked

The bridge is pulling data. This prints a recent timestamp and your tickers:

python3 -c "
import json
d = json.load(open('appfiles/data/snapshot.json'))
print('generated:', d['meta']['generatedAt'])
for acct, v in d['data'].items():
    print('stocks :', [e['symbol'] for e in v['equities']])
    print('options:', sorted({o['symbol'] for o in v['options']}))
"

The dashboard is live. Open it and check the Portfolio page shows your real total rather than the demo numbers. The Example button in the header switches between your data and the built-in demo at any time.

07Day to day

Getting updates:

cd ~/Robinhood-Connection
git pull
cd appfiles && npm run build   # only if the dashboard changed
pm2 restart all                # on a laptop, restart the two commands

Two things trip everyone up once. Changed the bridge? Restart it — a running Python process keeps the old code in memory, so pulling alone changes nothing. Changed the dashboard? Rebuild it — Next.js compiles ahead of time, so new screens won't appear until npm run build runs.

08When something's wrong

What you seeWhat to do
Dashboard shows demo dataThe Example toggle is on, or no snapshot exists yet — click it in the header, and check appfiles/data/snapshot.json is there.
Data stuck at an old timeThe bridge stopped or its login expired. Check pm2 logs databridge, and log in again if it asks.
Login or MFA errorsRecheck .env. Robinhood must be on an authenticator app, not text messages — then set ROBINHOOD_TOTP_SECRET.
APP_DATA_DIR does not existThe path in .env is wrong. Use the full absolute path to appfiles/data.
Build killed on a PiOut of memory — add swap (step A1) and build again.
Morning Brief is emptyNormal on a weekend. It only rebuilds on trading days and keeps the last board until then.

Stuck on something not listed? Hand Claude this guide plus whatever the terminal printed, and it will work out what happened.

09Keeping your account safe

  • Your credentials live only in databridge/.env on your own machine. That file is git-ignored and never leaves the computer.
  • appfiles/data/ holds your real positions and is git-ignored too. Only the synthetic Example dataset ships in the repository.
  • The bridge cannot trade. It reads positions and market data; there's no order path in the code at all.
  • Forking this publicly? Run git status before your first push and confirm neither .env nor anything under appfiles/data/ is listed.
